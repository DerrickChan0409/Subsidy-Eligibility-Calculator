# Project Summary

Project Title: Subsidy Eligibility Calculator

Project Description: 
The application helps low-income households determine whether they qualify for various government subsidies. Users enter their household information, and the system calculates eligibility based on predefined rules. 
Eligible subsidies are displayed along with the estimated assistance and application requirements.

The Four Features from this App:

Feature #1 — Applicant Registration

User enters:

Full Name
IC Number
Monthly Income
Number of Dependents
Employment Status
Disability Status (Yes/No)

After inputing all the important information, the user can save their information.

Feature #2 - Subsidy Calculation

| Subsidy              | Condition        |
| -------------------- | ---------------- |
| B40 Financial Aid    | Income < RM3,000 |
| Education Assistance | Dependents ≥ 3   |
| Disability Allowance | Disability = Yes |
| Senior Citizen Aid   | Age ≥ 60         |

The system displays every subsidy the applicant qualifies for.

Feature #3: Applicant Management

1) View all applicants
2) Search applicants
3) Edit applicant information
4) Delete applicant

Feature #4: Generate Eligibility Report

It will display something like this:

Applicant Summary

Name:
Ali bin Ahmad

Income:
RM2,200

Dependents:
4

Eligible Subsidies:

✓ B40 Financial Aid

✓ Education Assistance

✓ Utility Assistance

User can save this as a text file.

The four UI screens:

Home Dashboard --> Applicant Registration --> Eligibility Calculator --> Applicant Records --> Report Screen
